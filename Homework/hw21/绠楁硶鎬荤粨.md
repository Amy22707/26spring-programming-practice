# 第一份 PPT 算法与主要内容总结

1. 课程主题是利用稀疏性处理高维数据，并引入压缩感知：不先读取完整原始数据，而是通过较少的线性测量值恢复稀疏信号。
2. 设未知信号 z∈R^n 是 k-稀疏的，设计随机测量矩阵 A∈R^{m×n}，观测 b=Az。当 m<n 时线性方程欠定，一般解不唯一；但若 z 稀疏，可用远少于 n 的测量恢复。
3. 压缩感知定理指出，当 A 的元素独立服从标准高斯分布，且 m=O(k log(n/k)) 时，以高概率可同时恢复所有 k-稀疏信号。
4. 直接求最少非零坐标的 l0 最小化是 NP-hard，因此用 l1 最小化替代：min ||x||_1 s.t. Ax=b。l1 范数在几何上倾向于产生稀疏解，同时可高效求解。
5. l1 最小化可以转化为线性规划：引入辅助变量 y_i 表示 |x_i|，求 min sum y_i，约束 Ax=b, y_i-x_i>=0, y_i+x_i>=0。
6. PPT 后半部分介绍线性规划、LP solver、单纯形法的基本思想，包括标准型、基本可行解、entering/leaving variable、pivot 比值规则，以及 Phase I/Phase II 处理初始可行基。
