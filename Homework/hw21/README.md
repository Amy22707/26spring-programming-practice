# 压缩感知作业包

由于当前上传的 PDF 只有作业要求，没有包含 `tree.txt` 数据文件，无法在这里给出最终数值。

使用方法：
1. 从作业链接下载数据，确保 `tree.txt` 和 `cs_hw.py` 放在同一目录。
2. 安装依赖：`pip install numpy scipy matplotlib reportlab`。
3. 运行：`python cs_hw.py --tree tree.txt --seed 0`。
4. 程序会生成 `results.json`、`trend.png`、`report.pdf`。
